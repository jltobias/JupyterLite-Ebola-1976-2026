# Ebola history lab

Open the **notebooks** folder and run `timeline.ipynb`, `geography.ipynb`, or `sources.ipynb` with the **Python (Pyodide)** kernel. The first launch downloads the browser runtime, so an internet connection is needed. After opening a notebook, use **Run → Run All Cells**. Change the year and virus filters in the code cells to explore the 15 selected StoryMap stops.

The bundled `data/tour-stops.json` is a curated teaching table copied from the [StoryMap](https://jltobias.github.io/JupyterLite-Ebola-1976-2026-StoryMaps/). Its coordinates are approximate orientation points, not patient locations, and its stop counts are **not case counts**. Source links and event dates travel with each record. For outbreak totals, consult the dated [WHO](https://www.who.int/emergencies/disease-outbreak-news/item/2026-DON630) and [CDC](https://www.cdc.gov/ebola/outbreaks/) reports and the project's [references](https://github.com/jltobias/JupyterLite-Ebola-1976-2026-StoryMaps/blob/main/REFERENCES.md).

The [Jupyter Book](https://jltobias.github.io/JupyterLite-Ebola-1976-2026-StoryMaps/book/) explains the historical and spatial context. The lab runs locally in your browser; files you edit are stored in that browser until you download them.
